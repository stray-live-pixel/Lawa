# Lawa UI

Все экраны `lawa serve` написаны на React и TypeScript. Vite собирает их в
статические HTML, CSS и JavaScript. Node.js нужен разработчику; установленный Go
бинарник раздаёт встроенную сборку без Node.js, CDN или отдельного сервера UI.

## Разработка

Нужны Go из `../go.mod` и Node.js 22.12+ (ветка 22 в `.nvmrc`). Из корня проекта:

```sh
go run ./cmd/lawa serve --root /absolute/path/to/runs --listen 127.0.0.1:60800
```

В другом терминале:

```sh
cd ui
npm ci
npm run dev
```

Vite напечатает локальный адрес. Он проксирует API и ресурсы на Go; переменная
`LAWA_UI_BACKEND` меняет адрес backend. Origin и Host сохраняются, поэтому проверка
origin для удаления работает и через dev proxy. Используйте отдельное тестовое
хранилище: действия UI применяются к реальному выбранному `--root`.

## Статическая сборка

```sh
cd ui
npm run format:check
npm test
npm run build
cd ..
go build -o bin/lawa ./cmd/lawa
```

Результат — `internal/dashboard/web/`. Он хранится в Git вместе с исходниками и
`package-lock.json`: после правки UI коммитьте пересобранные файлы. CI выполняет
`npm ci`, тесты и сборку, затем проверяет отсутствие расхождений. Обычный `go build`
использует сохранённую статику; его самого недостаточно для пересборки frontend.

Можно раздавать эту папку любым статическим сервером. Для рабочих данных всё равно
нужен Go backend на том же origin: проксируйте перечисленные ниже API/ресурсы,
а `/`, `/preview`, `/graph/:run` направляйте на `index.html`. `npm run preview`
проверяет только статическую сборку; без такого прокси данные не загрузятся.

## Устройство и расширение

- `src/App.tsx` — маршруты, фильтры URL, расписание и главная страница.
- `src/components/Tree.tsx`, `RunInfo.tsx` — дерево, детали и действия запуска.
- `WorkflowGraph.tsx` — React Flow и раскладка Dagre; отдельный lazy chunk.
- `Trace.tsx` — курсорное чтение сообщений, изоляция turn, ограничение памяти.
- `ImageExport.tsx` — явный PNG-экспорт через локальный PlantUML, выбор темы.
- `Continuation.tsx` — выбор и копирование контекста в новый чат.
- `components/ui.tsx` — общие кнопки, статусы, выбор и модальные окна Gravity UI.
- `styles.css` — компоновка и токены Gravity UI для обеих тем.
- `hooks/api.ts` — последовательный polling, отмена при уходе, защита от старых ответов.
- `types.ts` — DTO API; PascalCase соответствует существующим Go структурам.

Новые библиотеки устанавливаются через `npm install <package>`. Повторяющиеся
элементы добавляйте в `components/ui.tsx` или отдельные компоненты. Доступность
диалогов (focus trap, Escape, подписи) обеспечивает Gravity UI; не заменяйте его ручным
управлением DOM. [React Flow](https://reactflow.dev/api-reference/react-flow),
[Gravity UI](https://gravity-ui.com/),
[Vite build](https://vite.dev/guide/build).

Раскладка графа зависит только от топологии: polling сохраняет масштаб и выбранный
кубик. Посещения различаются durable key; отчёт и промпт относятся к выбранному
исполнению. Поток сообщений отображается как текст; отчёт, память и промпт — как безопасный Markdown.

## Плотность интерфейса

Рабочая область занимает всю ширину и оставшуюся высоту окна. Дерево, граф и
детали разделяются одиночными линиями без вложенных рамок. Отступы задаются внутри
панелей управления и текстовых блоков; вокруг полотна графа полей нет. Вкладки
отмечают активный экран подчёркиванием и прокручиваются горизонтально на узком
экране. Рамки полей ввода, узлов и индикатор клавиатурного фокуса сохраняются.

## Темы и компоненты

Все элементы управления используют `@gravity-ui/uikit`, иконки —
`@gravity-ui/icons`. Radix и Lucide удалены. `components/Theme.tsx` оборачивает
приложение в Gravity ThemeProvider и задаёт русский язык встроенных элементов.

По умолчанию выбрана системная тема: `prefers-color-scheme` отслеживается без
перезагрузки. В шапке dashboard и отдельного графа доступны «Системная», «Светлая»
и «Тёмная». Выбор сохраняется в `localStorage` под ключом `lawa-theme`; при ошибке
хранилища переключение продолжает работать до закрытия страницы. Неизвестное
сохранённое значение трактуется как системное. Палитра графа, Markdown, диалогов
и popup использует те же токены; смена темы не пересоздаёт граф и его масштаб.

React Flow и Dagre остаются движком схемы: узлы используют Gravity Card, кнопки
масштаба — Gravity Button/Icon. Семантические HTML-контейнеры и безопасный Markdown
не заменяются UI-библиотекой. Экспорт PNG изначально использует текущую тему UI,
после ручного выбора тема картинки независима от переключения приложения.

Панели вкладок монтируют содержимое только при выборе, чтобы скрытая вкладка не
запускала polling и не открывала диалоги. Focus trap и возврат фокуса делегированы
Gravity Modal; подтверждение удаления сохраняется отдельным явным действием.

## HTTP-контракт

| Маршрут | Назначение |
| --- | --- |
| `GET /api/dashboard` | Дерево, фильтры, пагинация, расписание; query как на главной |
| `GET /api/preview` | Демонстрационные данные без чтения хранилища |
| `GET /api/graph/{run}` | Узлы, связи, исполнения, отчёты, промпты |
| `GET /api/trace/{run}` | Live-вывод с курсором и необязательным visit |
| `POST /api/runs/{run}/stop-and-delete` | Подтверждённая остановка и удаление; проверка Origin |
| `/memory/…`, `/events/…`, `/uml/…` | Существующие текстовые ресурсы и старые PNG |
| `GET /graph-image/{run}?theme=dark` | PNG по запросу; `light`, `download=1` |
| `/assets/lawa-logo.png` | Встроенный логотип |
| `/ui/assets/…` | Хешированные JS/CSS; долгий immutable cache |

Точные URL ресурсов и действий приходят в DTO; frontend не конструирует пути к
файлам. JSON и HTML оболочка не кешируются. Сервер возвращает 404 для неизвестных
API и ресурсов, а не маскирует их SPA-оболочкой. Пользовательские run не попадают
в сборку. `ui/licenses.json` содержит лицензии npm-зависимостей сборки.

## Markdown и результат кубика

Результат и память рендерятся через `react-markdown` + GFM. Копирование возвращает
исходный Markdown, включая заголовки, таблицы и code fences. HTML не исполняется;
изображения представлены ссылками, чтобы не загружать адреса из частных сообщений
автоматически. При отказе Clipboard API доступно ручное копирование исходника.

«Память кубика» и «Сообщения и действия» открывают модалки и читают данные только
после клика. Промпт вынесен во вкладку «Продолжить в новом чате Codex» и сохраняет
выбор кубика/посещения из графа. Скрытые handles остаются в DOM ради геометрии
React Flow; направления рёбер обозначаются стрелками.
