# Универсальная проверка кода через Merilo

`code-review.json` содержит десять независимых категорий: требования, корректность,
жизненный цикл и параллельность, ошибки, безопасность, совместимость,
производительность, поддерживаемость, тестирование и документация.
Конфиг не зависит от языка, проекта или конкретного изменения.

## Материал

Передай требования, diff и необходимый окружающий код: вызывающие функции,
контракты, тесты и результаты проверок, изменённую документацию. Для оценки
совместимости нужно исходное поведение. Ссылок недостаточно: Merilo не открывает
их и не читает репозиторий. Не включай секреты и конфигурацию доступа.
Предел контекста — 1 МБ.

## Запуск

Нужны Merilo, Codex CLI и вход через ChatGPT (`codex login status`).
Из каталога, содержащего `.merilo`:

```sh
merilo -config .merilo/code-review.json -context - < /absolute/review-context.txt > /absolute/review-result.json
```

Настройки: Codex по подписке, `gpt-6-sol`, effort `medium`, по одному вызову
на категорию, до пяти одновременно. Это десять оценок; повторы некорректных
ответов могут увеличить число попыток. Запуск расходует лимиты подписки.
Платного резервного провайдера нет. Модель и effort можно заменить в `defaults`
на поддерживаемую комбинацию, число повторов — в `defaults.repeats`.

## Интерпретация

Каждая категория возвращает один из пяти результатов:

- **Существенные проблемы** — конкретный недостаток с существенными последствиями.
- **Небольшие проблемы** — конкретный недостаток с ограниченными последствиями.
- **Проблем не выявлено** — в достаточном переданном материале проблем не обнаружено.
- **Недостаточно данных** — для вывода нужен дополнительный материал.
- **Не применимо** — материал явно показывает, что категория к изменению не относится.

Сначала проверь код выхода и `checks[].status`: `completed` означает выполнение
оценки, а не успешное ревью. `error` не является результатом проверки кода.
При нескольких повторах `choice` выбирает максимум медианных вероятностей,
а не большинство голосов. Вероятности не являются гарантией правильности.

Категории не усредняются в общий балл. Merilo не возвращает объяснения дефектов:
результат помогает выбрать область для обычного ревью, где нужно установить
конкретные место, сценарий и последствия. «Проблем не выявлено» не заменяет
тесты и не означает автоматическое разрешение на слияние.
