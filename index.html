02 / Поток вместо очереди

Один агент не должен делать всё по очереди.

Сравнение работы без Lawa и с Lawa
Сценарий Без Lawa С Lawa
Независимые задачи Идут по очереди Стартуют параллельно
Зависимости Контролирует человек Проверяет граф
Контекст Смешивается в одном чате Разделён по агентам
Пауза или сбой Продолжение вручную resume с того же run
Общий итог Нужно сводить вручную Собирает итоговый кубик

Короткую линейную задачу проще оставить одному агенту. Lawa раскрывается, когда есть несколько независимых веток и общий этап сборки.

03 / Как это работает

Опишите граф.
Дальше поток ведёт Lawa.

  1. 01Проверяет зависимости и циклы до запуска.
  2. 02Запускает готовые задачи в отдельных чатах Codex.
  3. 03Собирает ветки после успешного завершения входов.

05 / Быстрый старт

Направьте
свой первый поток.

macOS и Linux · один бинарник · работа из привычного чата Codex.

Промпт для Codex-агента

Установи последнюю стабильную версию Lawa из GitHub Release. Сначала запусти install.sh с --plan и покажи план установки. Перед системными командами отдельно запроси моё разрешение. После подтверждения установи Lawa и проверь lawa version, lawa help и установленный скилл.

Скопируйте текст в Codex: агент покажет план до изменений и запросит нужные подтверждения.
